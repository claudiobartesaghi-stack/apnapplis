# Mod per Claude Code

## token-panel

Pannello dei consumi token giornalieri e settimanali, in numeri e in percentuale.
Mostra anche le percentuali dei limiti dell'account (finestra 5 ore e 7 giorni).

Uso, da terminale:

    claude --plugin-dir mod/token-panel

Poi, in Claude Code: `/token-panel`.

Stato: scritto e validato con `claude plugin validate`, mai eseguito dal vivo.
